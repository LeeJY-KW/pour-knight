# Pour Knight (가제)

"컵 붓기 + 배수 게이트 + 웨이브 디펜스" 장르의 **픽셀 아트 모바일 게임 프로토타입**입니다.
광고 SDK가 전혀 없고, 외부 라이브러리·이미지·사운드 파일도 쓰지 않습니다. 그래픽은 코드 안의 픽셀 문자열로 그리고, 효과음은 WebAudio로 합성합니다.

## 실행

`index.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 띄워도 됩니다.

```powershell
python -m http.server 8765
```

이후 `http://localhost:8765`에 접속하면 됩니다. 같은 와이파이의 휴대폰에서 `http://<PC IP>:8765`로 접속하면 폰에서도 플레이할 수 있습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 누르고 있기 (터치/마우스) | 컵을 기울여 구슬 붓기 |
| 좌우 드래그 | 컵 이동 |
| 화면 오른쪽 위 `x1/x2` | 게임 속도 2배 |
| 화면 오른쪽 위 `II` | 일시정지 (보유 스킬 확인, 포기) |
| PC: ←/→ 또는 A/D, Space, P/Esc | 이동 / 붓기 / 일시정지 |
| PC: M / N | 음악 켜기·끄기 / 효과음 켜기·끄기 |

## 게임 루프

1. 컵에서 구슬을 붓는다 → 게이트(x2, x3…)를 통과할 때마다 구슬이 늘어난다
2. 바닥에 닿은 구슬은 기사의 화살이 된다. 적을 처치하고 남은 피해량은 다음 적에게 넘어간다
3. 웨이브를 클리어하면 코인으로 스킬 카드를 산다 (3장, 스킬에 따라 4장)
4. **한 판은 20웨이브**(10~15분)이고, 4웨이브마다 지역이 바뀌어 한 판에 5개 지역을 모두 지난다
   - 지역 순서: 초원 → 모래 사막 → 얼음 설원 → 밤의 숲 → 화산 지대
   - 보스: W5 골렘 왕, W10 슬라임 왕(분열), W15 박쥐 군주(박쥐 소환), **W20 화산 거인**(최종 보스, 늑대 소환)
5. 최종 보스를 쓰러뜨리면 **승리**(보석 +25 보너스). 쓰러져도 보석을 얻는다 → 캠프에서 영구 강화 → 다음 판은 더 멀리 간다

## 오래 즐길 수 있게 넣은 것들

- **난이도 사다리**: 보통 클리어 → 어려움(보석 x1.6) 해금 → 어려움 클리어 → 악몽(보석 x2.5, 웨이브 사이 회복 없음) 해금
- **캠프(영구 강화) 8종**: 시작 체력, 공격력, 컵 용량, 시작 코인, 코인 획득, 회피, 시작 스킬, 보석 획득
  - 전부 최대로 올리려면 보석이 약 2,700개 필요합니다 (한 판에 보통 10~60개, 악몽 승리는 150개 이상)
- **업적 16종**: 각각 보석 보상이 있습니다 (난이도별 클리어, 전설 스킬, 구슬 500개, 한 방 1,000 피해, 노데미지 보스 등)
- **옷장(코스튬) 10종**: 외형과 화살 색만 바꾸고 능력치는 그대로입니다
  - 보석으로 구매: 진홍 기사, 숲의 사냥꾼(각 40), 왕실 근위대(250)
  - 진행도로 자동 해금: 슬라임 옷(누적 처치 1,000), 서리 기사(보통 클리어), 그림자 기사(어려움 W10), 화염 기사(어려움 클리어), 악몽 기사(악몽 클리어), 황금 기사(업적 10개)
- **다음 목표 안내**: 게임오버 화면에 지금 살 수 있는 캠프 강화, 옷장 아이템, 다음 해금 조건을 보여줍니다
- **자동 저장**: 상점에 들어갈 때마다 저장하므로, 앱을 꺼도 "이어하기"로 이어서 할 수 있습니다
- **구슬 10종**: 스킬로 등장 확률을 올립니다

  | 분류 | 구슬 | 효과 |
  |---|---|---|
  | 가치 | 흰 / 은 / 금 / 루비 | 가치 x1 / x2 / x3 / x5 |
  | 잭팟 | 무지개 / 다이아몬드 | 가치 x10 / x25 |
  | 원소 | 화염 / 얼음 / 번개 / 폭탄 | 그 구슬로 만든 화살에 화상 / 감속·빙결 / 주변 2명 감전 / 폭발이 붙음 |

  - 원소 구슬도 게이트를 지나면 같이 늘어나므로, 원소 구슬을 게이트로 불리면 원소 화살이 쏟아집니다.
  - 현재 쌓인 원소 탄약은 기사 머리 위에 색깔 칩으로 표시됩니다.
- **스킬 80종 + 전설 진화 13종**: 생존 / 공격 / 구슬 / 게이트 / 경제 / 트리거 / 구슬 종류 계열
  - **구슬 종류 스킬**: 은·루비·다이아몬드·화염·얼음·번개·폭탄 구슬
    - 연금술(게이트 통과 시 구슬 등급 상승: 흰→은→금→루비), 보석 세공(보석 구슬 가치 +50%), 원소 증폭(원소 효과 +50%)
    - 분광기(무지개 구슬 → 원소 탄약 보충), 다이아 컷(다이아 착지 → 전체 공격 + 구슬 +10), 루비 심장(루비 착지 → 체력 +1)
    - 전설: 백금 구슬(은 x4), 용의 심장(루비 x10), 원소 융합(원소 화살이 4가지 효과를 모두 가짐)
  - 독 화살, 밀쳐내기, 저격, 천벌(낙뢰), 시체 폭발, 시간 왜곡, 컵 충격파, 피의 계약, 보호막, 현상금, 구슬 회수, 첫 관문, 거인의 컵, 황금 바닥, 행운의 별 등
  - **트리거 스킬 15종**: 무언가 터지면 구슬이 컵으로 날아 들어옵니다
    - 치명적 보충(치명타 → +2), 전리품 구슬(처치 20% → +2), 콤보 보너스(콤보 10마다 +6), 폭발 회수(폭발이 3명 이상 → +4)
    - 전류 충전(번개 맞춘 수만큼), 잭팟 게이트(게이트 통과 중 가끔 +8), 역경의 힘(피격 → +6), 반격(회피 → 강한 반격 화살)
    - 황금 연쇄(황금 구슬 착지 → +1), 보급 상자(웨이브 시작 +20), 과충전(리필 첫 15% 황금), 처형 보상, 구슬 비(10초마다 +10)
    - 피의 구슬(체력 30% 이하 구슬 가치 2배), 보스 전리품(보스 처치 → 코인 +50, 구슬 +30)
    - 구슬 → 화살 → 치명타 → 구슬로 무한히 불어나지 않도록, 연쇄될 수 있는 트리거에는 짧은 재사용 대기시간이 있습니다
  - **전설 진화**: 스킬을 최대 레벨까지 올리면 상점에 진화 카드가 나옵니다
    - 연사 → 폭풍 석궁, 급소 사격 → 필살, 황금 구슬 → 미다스의 손, 멀티샷 → 화살비
    - 그림자 망토 → 유령 망토(회피 시 구슬 +4 & 반격), 큰 컵 → 무한의 잔(6초마다 구슬 +15) 등
  - 바로 전 상점에 나왔던 카드는 다시 나올 확률이 낮습니다 → 한 판에 보통 35~40종을 봅니다
- **적 9종 + 보스 4종**: 폭탄병(접촉 폭발), 분열 슬라임, 방패 해골(피해 60% 감소), 주술사(주변 적 회복) 등
- **구덩이 레이아웃 16종**: 움직이는 게이트, 플링코 핀, 분리벽, 깔때기, 그리고 아래 장치들을 섞은 레이아웃 7종

### 구덩이 장치

| 장치 | 효과 |
|---|---|
| x2 / x3 게이트 | 지나간 구슬이 배수만큼 늘어남 |
| `^x2` 리버스 게이트 (하늘색) | 늘린 뒤 위로 튕겨 올림. 위쪽 게이트를 한 번 더 통과 |
| 스프링 (주황 발판) | 구슬을 위로 발사. 처음 한 번은 위쪽 게이트 재통과 가능 (구슬당 최대 2회) |
| x2 범퍼 (보라 원) | 부딪힌 구슬이 둘로 분열 (범퍼당 1회). 궤도를 도는 범퍼도 있음 |
| 포털 IN → OUT | 구슬을 위로 순간이동시켜 게이트를 다시 통과 (구슬당 1회) |
| GOLD 게이트 | 구슬이 황금 구슬(가치 3배)로 바뀜 |
| `/2` 함정 게이트 (빨강) | 구슬 절반이 사라짐 → 피해서 부어야 함 |
| 회전 막대 | 구슬을 쳐냄 |
| 바닥 x2/x3 구역 | 그 구역에 떨어진 구슬의 가치가 배수 |

같은 줄의 게이트는 "넓은 게이트" 스킬을 아무리 사도 서로, 그리고 벽·경사로와 겹치지 않습니다. 남은 빈 공간까지만 넓어집니다.

### 밸런스

자동 플레이 봇(맨 위 게이트만 겨냥하고 상점은 싼 것부터 다 사는 단순한 봇)으로 측정한 결과입니다. 사람이 게이트를 노리고 부으면 이보다 훨씬 오래 버팁니다.

| 난이도 | 캠프 강화 | 결과 (20웨이브 중) |
|---|---|---|
| 보통 | 없음 | W10~14에서 쓰러짐 |
| 보통 | 절반 | 가끔 승리 (봇 기준 1/4) |
| 보통 | 최대 | 대부분 승리 (봇 기준 2/3) |
| 어려움 | 최대 | 대부분 승리 |
| 악몽 | 최대 | W12~20 (최종 보스에서 막힘) |

한 판(20웨이브) 승리까지 걸리는 시간은 약 11~15분입니다(상점에서 고르는 시간 포함).

## 음악과 효과

음악은 오디오 파일 없이 코드로 만듭니다. `js/music.js`의 칩튠 엔진이 곡마다 짧은 레시피(조성, 음계, 코드 진행, 템포, 악기, 시드)를 받아 곡을 생성합니다.
- 시드가 같으면 항상 같은 곡이 나오므로, 지역마다 고유한 테마가 됩니다.
- 곡 8개: 타이틀, 상점, 지역 5종(초원/사막/설원/밤/화산), 보스
- 구성: 16마디(테마 → 응답 → 브리지 → 멜로디 없이 반주만 나오는 구간 → 반복), 한 바퀴 25~45초
- 악기: 펄스파 리드(25/50%) 또는 삼각파, 삼각파 베이스·아르페지오, 노이즈 드럼
- 귀가 아프지 않도록 처리했습니다
  - 모든 음은 D5(약 587Hz) 이하로 제한합니다.
  - 음악·효과음 출력에 하이컷 필터(3kHz / 4.2kHz)를 걸고, 하이햇은 중고역으로 낮췄습니다.
  - 효과음도 대부분 한 옥타브 정도 낮춘 삼각파로 바꿨습니다.
- 화면이 바뀔 때 곡이 자연스럽게 전환(크로스페이드)되고, 일시정지하면 볼륨이 작아집니다.

곡 분위기를 바꾸려면 `SONGS`의 `seed`(멜로디), `prog`(코드 진행), `bpm`, `scale`, `drums`를 고치면 됩니다.

시각 효과
- 지역별 날씨: 꽃잎, 모래바람, 눈, 반딧불, 불씨
- 처치 연출: 코인이 HUD로 날아가는 애니메이션, 하얀 포프 링
- 콤보 카운터: 1.2초 안에 5마리 이상 처치하면 표시
- 보스: 등장 시 WARNING 경보와 화면 점멸, 처치 시 화면 섬광
- 피격 시 화면 테두리가 붉게 번쩍임
- 웨이브 클리어 시 색종이
- 그 밖에 석궁 발사 불꽃, 게이트 반짝임, 바닥 수집기 발광

메뉴 효과: 패널 등장 애니메이션, 카드 구매 섬광, 새로고침 시 카드가 다시 나오는 애니메이션, 에픽 카드 반짝임, 보석 숫자 카운트업

## 파일 구조

```
index.html        진입점
style.css         레이아웃 + 픽셀 스타일 UI
js/font.js        3x5 비트맵 픽셀 폰트
js/sprites.js     픽셀 스프라이트(기사 + 코스튬 9종, 적 9종, 보스 3종, 컵, 아이콘 40여 개)
js/audio.js       합성 효과음(톤 + 노이즈), 오디오 출력 관리
js/music.js       절차적 칩튠 BGM 엔진 + 곡 8개
js/levels.js      구덩이 레이아웃 9종, 지역 5종, 적 스펙, 웨이브 구성
js/skills.js      스킬 카드 37종 + 가격
js/meta.js        보석, 캠프 강화, 업적, 코스튬 해금, 체크포인트, 자동 저장
js/game.js        물리(구슬/게이트/경사로), 전투, 스킬 효과, 렌더링
js/ui.js          타이틀 / 캠프 / 기록 / 도움말 / 상점 / 일시정지 / 게임오버
js/main.js        입력, 화면 크기 조정, 메인 루프
```

내부 해상도는 270x480(9:16)이고, 확대해서 픽셀이 또렷하게 보이도록 그립니다.
레이아웃 좌표는 216x384 기준으로 작성하고 1.25배(`LS`)로 키워서 씁니다.

## 밸런스 조정 위치

| 항목 | 위치 |
|---|---|
| 적 체력·속도·피해·코인 | `js/levels.js`의 `ETYPES` |
| 난이도별 배율·해금 조건 | `js/levels.js`의 `DIFFS` |
| 구덩이 장치 배치 | `js/levels.js`의 `LAYOUTS` (`bumpers`, `portals`, `springs`, `spinners`, `zones`, 게이트의 `rev`/`trap`/`goldify`) |
| 웨이브별 적 등장 시점·비중 | `js/levels.js`의 `ROSTER` |
| 웨이브별 체력 증가 | `js/game.js`의 `spawnEnemy` 안 `hs` |
| 한 판 웨이브 수, 보스 순서 | `js/levels.js`의 `RUN_WAVES`, `BOSSES` |
| 스킬 효과와 가격 | `js/skills.js` |
| 캠프 강화 | `js/meta.js`의 `META_UPS` |
| 업적 | `js/meta.js`의 `ACHS` |

새 구덩이 레이아웃은 `LAYOUTS`에 `gates`와 `segs`(경사로 선분), `pegs`를 추가하면 됩니다.

세이브는 브라우저 localStorage의 `pourknight_v2` 키에 들어 있습니다. 개발자 도구에서 지우면 처음부터 시작합니다.

## 모바일 앱으로 만들기 (광고 없이)

웹 게임이라서 [Capacitor](https://capacitorjs.com/)로 감싸면 Android/iOS 앱이 됩니다.

1. Node.js 설치
2. 웹 파일(`index.html`, `style.css`, `js/`)을 `www/` 폴더로 옮김
3. `npm init -y`, `npm i @capacitor/core @capacitor/cli @capacitor/android`
4. `npx cap init "Pour Knight" com.yourname.pourknight --web-dir www`
5. `npx cap add android`, `npx cap open android` → Android Studio에서 빌드
