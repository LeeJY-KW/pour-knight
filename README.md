# Pour Knight

**지금 플레이하기: https://leejy-kw.github.io/pour-knight/**

## 이야기

평화롭던 초원 마을에 어느 날 화산 깊은 곳에서 거인이 깨어났습니다.
거인이 불러낸 슬라임과 박쥐, 골렘 떼가 사막과 설원, 밤의 숲을 지나 마을로 몰려오고 있습니다.

마을에 남은 건 청록 투구를 쓴 기사 한 명과, 대대로 내려오는 낡은 컵 하나뿐.
이 컵에서 쏟아지는 구슬은 바닥에 닿는 순간 화살이 되고,
구덩이 곳곳의 마법 게이트를 지날 때마다 두 배, 세 배로 불어납니다.

컵을 기울여 구슬을 퍼붓고, 게이트로 불려서, 몰려오는 몬스터를 쏘아 넘기세요.
스무 번째 웨이브 끝에서 기다리는 화산 거인을 쓰러뜨리면 마을을 지켜낸 것입니다.

## 플레이

- 화면을 누르고 있으면 컵이 기울어 구슬을 붓고, 좌우로 끌면 컵이 움직입니다.
- 게이트를 지난 구슬은 늘어나고, 바닥에 닿은 구슬은 기사의 화살이 됩니다.
- 웨이브를 깰 때마다 코인으로 스킬을 골라 나만의 빌드를 만들어 보세요.
- 쓰러져도 보석이 남습니다. 캠프에서 기사를 단련하고 다시 도전하세요.
- 보통을 깨면 어려움이, 어려움을 깨면 악몽이 열립니다.

광고 없이, 브라우저에서 바로 즐기는 픽셀 게임입니다.
